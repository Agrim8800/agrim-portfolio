# Agrim Jain — Personal Portfolio

A minimal, dark-themed portfolio for Agrim Jain, a first-year B.Tech Computer Science & Engineering student at KIET (2026–2030).

## Features

- Responsive layout for desktop and mobile
- About, learning, projects, education, and contact sections
- Expandable project details
- Email and GitHub links
- Keyboard navigation and reduced-motion support

## Run locally

Open `index.html` in your browser. No installation or build step is required.

## Technology

Semantic HTML and CSS. Styles and favicon are included in `index.html`; there are no external dependencies.

## Deploy with GitHub Pages

In repository Settings → Pages, choose **Deploy from a branch**, select **main** and **/ (root)**, then save.

## Customize

Edit the text and links in `index.html`. Theme colors are defined in the `:root` CSS variables.
